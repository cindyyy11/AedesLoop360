## Migrations and data notes

Migration 002 stores the initiating operator on simulation jobs. Migration 003 adds `approval_expires_at`; new approvals expire after 30 minutes, while legacy approvals without an expiry fail closed. Migration 004 adds append-only sample count revision history and database triggers. Fresh SQLite migration, a simulated legacy revision-002 upgrade through revision 004, and the full API tests passed. The initial migration’s live-metadata pattern remains a historical reproducibility risk, and PostgreSQL migration behavior is not verified.

All block names, coordinates, candidate annotations, egg counts and actions are fictional or simulated. Candidate containers do not establish larvae, egg activity does not establish adult abundance or confirmed Aedes species, and recorded simulated actions do not establish biological effectiveness or dengue impact. See [ADR-004](adr/ADR-004-local-fixture-evidence-and-review.md) for fixture classification and count revision decisions.
