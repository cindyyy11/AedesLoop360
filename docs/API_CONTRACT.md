# API Contract — FastAPI `/api/v1`

The live OpenAPI generated by FastAPI becomes canonical; this document is the *design intent*. Regenerate typed web clients from `/openapi.json`, and keep client and API schema in sync. Authenticated routes require tenant-scoped RBAC. Use RFC 7807-like consistent error responses with `code`, `message`, `correlation_id`, `details`.

## 1. Route map

| Method | Path | Actor | Meaning |
|---|---|---|---|
| GET | `/health` | all | readiness + db status (no secrets) |
| GET | `/blocks` | member | list four blocks, monitoring-quality overview |
| GET | `/blocks/{id}/summary` | member | samples/observations/active tasks and explanation |
| GET | `/assets?block_id=` | member | map assets, access and recent observations |
| GET | `/assets/{id}/history` | member | longitudinal inspection/action evidence |
| POST | `/media/upload-url` | operator/inspector | private signed upload intent with type/size validation |
| POST | `/inspections` | inspector/operator | site observation with evidence/provenance |
| POST | `/inspections/{id}/analyse` | operator | asynchronous CV prediction job |
| GET | `/inspections/{id}/findings` | member | detection results and status |
| POST | `/findings/{id}/review` | reviewer | record uncertainty/validation, no clinical inference |
| GET | `/drones/missions` | member | list simulation/planned missions |
| POST | `/drones/missions` | operator/coordinator | create proposed mission |
| POST | `/drones/missions/{id}/decision` | coordinator | approve/reject with reason/policy version |
| POST | `/drones/missions/{id}/simulate` | operator | simulate only after approval; idempotent |
| POST | `/drones/missions/{id}/abort` | operator | abort, immutable record |
| GET | `/drones/missions/{id}/events` | member | chronological events |
| GET | `/ovitraps` | member | list sensors and device-health status |
| POST | `/ovitraps` | admin | register trap with site and safety fields |
| POST | `/ovitraps/{id}/samples` | trap device/reviewer | interval sample/image import |
| POST | `/ovitraps/samples/{id}/analyse` | reviewer | egg CV inference job |
| GET | `/ovitraps/{id}/samples` | member | samples with validity and provenance |
| GET | `/ovitraps/summary?block_id=&start=&end=` | member | normalised surveillance indicators |
| POST | `/ovitraps/{id}/service` | inspector | servicing and safety record |
| POST | `/planning/runs` | coordinator | generate versioned ranked inspection plan |
| GET | `/planning/runs/{id}` | member | evidence and recommended tasks |
| POST | `/planning/runs/{id}/approve` | coordinator | authorise task plan, not chemical spraying |
| GET | `/work-orders` | member | assigned tasks and queues |
| POST | `/work-orders` | coordinator | create inspect/repair/service task |
| PATCH | `/work-orders/{id}` | authorised assignee | update task within state rules |
| POST | `/work-orders/{id}/verify` | reviewer | independent site-outcome verification |
| GET | `/audit?entity_type=&entity_id=` | admin/coordinator | read immutable event history |
| POST | `/demo/reset` | demo admin only / local/demo | reset four-block sample fixture; never enabled in production |

No `/spray-real`, `/set-pesticide-dose`, `/launch-uav` or similar endpoints belong in this MVP.

## 2. Shared schema fragments

`ApiEnvelope<T> = { data: T, correlation_id: UUID, source_mode: "SIMULATED"|"BENCH_TEST"|"OBSERVED"|"IMPORTED" }` (use consistent pattern throughout, not duplicated differently).

`ErrorResponse = { code: string, message: string, correlation_id: string, details?: object }`.

`Idempotency-Key` required on creation of samples, mission event ingestion, simulations and intervention action records. Repeating same idempotency key/payload returns original result; conflicting payload returns 409.

## 3. Example: create an observation

```json
{
  "asset_id": "asset-p03",
  "observed_at": "2026-10-23T02:00:00Z",
  "source_mode": "SIMULATED",
  "source": "AERIAL_IMAGE",
  "water_state": "POSSIBLE_WATER",
  "evidence_quality": "PARTIAL_OCCLUSION",
  "media_id": "image-sample-001",
  "notes": "Possible standing water; ground inspection needed"
}
```

Response carries observation UUID, status `NEEDS_REVIEW`, source/provenance, matching asset and `can_auto_treat=false`.

## 4. Example: interval-based ovitrap sample

```json
{
  "source_sample_id": "B1-T1-2026W43-A",
  "interval_start": "2026-10-16T00:00:00Z",
  "interval_end": "2026-10-23T00:00:00Z",
  "sampling_effort_days": 7,
  "image_id": "image-egg-sample-001",
  "source_mode": "SIMULATED",
  "egg_count": 35,
  "count_method": "HUMAN_LABELLED_FIXTURE",
  "validity": "VALID"
}
```

If a CV job produces a revision, reference sample ID and model version; do not create another counted sampling interval. Two samples from the same trap may only be compared when collection boundaries and servicing provenance are defensible.

## 5. Example: planned drone mission

```json
{
  "block_id": "block-1",
  "mode": "SIMULATED",
  "purpose": "INSPECTION_WITH_HARMLESS_TARGET_DEMO",
  "approved_zone_id": "zone-demo-b1",
  "candidate_ids": ["finding-004"],
  "policy_version": "demo-policy-v1",
  "notes": "No real flight or chemical dispensing"
}
```

`POST /drones/missions/{id}/decision` body:

```json
{
  "decision": "APPROVE",
  "review_reason": "Fictional approved demo zone, harmless action only",
  "checked_items": ["SIMULATED_MODE", "AUTHORIZED_TEST_ZONE", "NO_CHEMICAL_PAYLOAD"]
}
```

The API rejects simulated execution if mission is not `APPROVED`, targets are `SKIP/UNCERTAIN`, mode is wrong, or policy changed. For bench mode, an independent local hardware interlock must also approve harmless water activation; web endpoint alone cannot arm.

## 6. Example: planning run

```json
{
  "strategy": "ADAPTIVE_RULES_V1",
  "budget": {"staff_hours": 12, "drone_survey_hours": 2},
  "sampling_window": {"start":"2026-10-16T00:00:00Z","end":"2026-10-23T00:00:00Z"},
  "enforce_minimum_coverage": true,
  "source_mode": "SIMULATED"
}
```

Response includes `run_id`, `evidence_snapshot_hash`, `model_version`, `block_priorities[]`, `recommended_tasks[]`, `excluded_evidence[]`, `uncertainty[]`, `budget_used`, `coverage_guardrail`, `explanation`. Explanations must include observable supporting records, not fabricated conclusions.

## 7. Security, behaviour, pagination

- Auth via validated identity provider or local dev JWT, role/tenant derived on server.
- Collection API pagination, UTC ISO timestamps, stable sorting, query-limit caps.
- Never expose internal object storage paths publicly. Serve signed reads after permission check.
- HTTP 403 cross-tenant; 409 invalid transition/duplicate conflict; 422 input validation; 503 worker/model unavailable with safe fallback status; always audit consequential failures/approvals.
- Every endpoint must include OpenAPI schemas, at least one valid test and negative authorization/validation tests.
